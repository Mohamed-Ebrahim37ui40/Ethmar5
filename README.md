# مزرعة أثمار – أدوات زراعية (PWA)

يعمل **بدون إنترنت** بعد أول فتح، ويمكن **تثبيته** على أي تليفون (أندرويد / آيفون) مثل تطبيق عادي.


## حقوق الاستخدام
- الاستخدام العادي للموقع والتثبيت على التليفون **مسموح**.
- **ممنوع** نسخ ملفات المصدر من GitHub وإعادة رفعها أو نشرها باسم آخر.
- انظر ملف `LICENSE` للتفاصيل.
- أي نسخة معدّلة بدون إذن تُعد انتهاكاً لحقوق النشر.

## الملفات
- `index.html` – التطبيق كامل
- `manifest.webmanifest` – بيانات التثبيت
- `sw.js` – التخزين للعمل أوفلاين
- `icon-192.png` / `icon-512.png` – أيقونة التطبيق

## رفع على GitHub من التليفون (خطوة بخطوة)

### 1) إنشاء مستودع
1. افتح **github.com** من متصفح التليفون (Chrome أو Safari).
2. سجّل دخول.
3. اضغط **+** → **New repository**.
4. الاسم مثلاً: `athmar-tools`
5. اجعله **Public**.
6. **لا** تضف README من جيت هب (سنرفع ملفاتنا).
7. اضغط **Create repository**.

### 2) رفع الملفات
1. في صفحة المستودع الفارغة اضغط **uploading an existing file**.
2. ارفع **كل** الملفات الموجودة في مجلد `athmar-pwa`:
   - index.html
   - manifest.webmanifest
   - sw.js
   - icon-192.png
   - icon-512.png
3. اكتب رسالة مثل: `أول رفع`
4. اضغط **Commit changes**.

### 3) تفعيل GitHub Pages
1. من المستودع: **Settings** → من القائمة اليسرى **Pages**.
2. تحت **Source** اختر **Deploy from a branch**.
3. Branch: **main** (أو master) و المجلد **/ (root)**.
4. احفظ **Save**.
5. انتظر دقيقة، سيظهر رابط مثل:
   `https://USERNAME.github.io/athmar-tools/`

### 4) فتح وتثبيت
- افتح الرابط من التليفون.
- **أندرويد (Chrome):** القائمة ⋮ → **تثبيت التطبيق** أو **Add to Home screen**.
- **آيفون (Safari):** زر المشاركة □↑ → **إضافة إلى الشاشة الرئيسية**.
- بعد التثبيت يفتح بدون شريط المتصفح ويعمل بدون نت.

## الثيم (يطبّق على كل الأدوات الداخلية)
زر 🌓 في أعلى الشاشة يدور بين:
- حسب النظام
- نهاري ☀️
- ليلي 🌙

الاختيار يُحفظ ويُرسل تلقائياً لكل الأدوات (مساحة البيفوت، الري، التقاوي، الإنبات، الحصاد، الفحص) فيتحول شكلها ليلي/نهاري معه.

## اللغة (مستقلة عن لغة النظام)
زر **ع / EN** في أعلى الشاشة يغيّر لغة الأدوات التي تدعم ثنائية اللغة (مثل مساحة البيفوت).  
لا يتأثر بلغة التليفون — أنت تتحكم من الزر فقط.

## نسخة احتياطية
زر **نسخة** يحفظ/يسترجع بياناتك (JSON) — مهم قبل مسح بيانات المتصفح.

## إعادة التثبيت بعد الحذف
1. من داخل التطبيق: **نسخة** → **إصلاح التثبيت** (يمسح Service Worker والكاش فقط، لا يمسح قراءاتك).
2. أغلق التطبيق تماماً من قائمة التطبيقات الحديثة.
3. افتح **نفس الرابط** من Chrome → ⋮ → **تثبيت التطبيق**.

لو ظهرت رسالة «سبق التثبيت» أو «تعذر الفتح»:
- Chrome → إعدادات الموقع لهذا الرابط → **مسح البيانات**
- أو اكتب في الشريط: `chrome://apps` واحذف أيقونة أثمار إن وُجدت
ثم أعد فتح الرابط وثبّت.
